My First Program

The first thing I wrote in Python was print("Hello, World!"). Later I wrote this loop:

    print("Hello", i)

The same idea in C++:

#include <iostream>

int main() {
    for (int i = 0; i < 3; i++) {
        std::cout << "Hello " << i << "\n";
    }
    return 0;
}
