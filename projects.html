My Projects

These projects reflect my interest in using software to solve practical problems for communities, individuals, and local businesses.

1. FixMyArea

FixMyArea is designed to let residents report community problems, including potholes and broken streetlights, so these issues can be tracked and addressed.

Focus: Community issue reporting.

2. MediNear

MediNear aims to help people quickly find nearby pharmacies that have the medicine they need, especially when locating medicine is urgent.

Focus: Medicine availability and pharmacy discovery.

View GitHub Repository

Focus: E-commerce for local businesses.
