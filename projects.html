1. FixMyArea

How I Built It

  1. Identify the community problem: reporting potholes and broken streetlights.
  2. Plan the information users need to submit a report.
  3. Design the reporting flow and the way submitted issues are displayed.
  4. Test the user flow and refine the project based on feedback.

Technologies Used

  • HTML5, CSS3, and JavaScript for the frontend.
  • Node.js and Express.js for the backend API.
  • PostgreSQL with Supabase for database services.
  • JSON Web Tokens (JWT) for authentication.
  • bcrypt for password hashing.

FixMyArea is designed to let residents report community problems, including potholes and broken streetlights, so these issues can be tracked and addressed.

Focus: Community issue reporting.

2. MediNear

How I Built It

  1. Identify the need to find nearby pharmacies with required medicine.
  2. Plan how users search for medicine and view pharmacy information.
  3. Design the pharmacy discovery and medicine availability experience.
  4. Test search and discovery flows and improve the user experience.

Technologies Used

  • HTML5, CSS3, and vanilla JavaScript for the frontend.
  • Node.js and Express.js for the backend API.
  • PostgreSQL, accessed with the pg package, for database storage.
  • bcrypt for password hashing and JSON Web Tokens (JWT) for authentication.
  • CORS and dotenv for backend configuration; nodemon for development.

MediNear aims to help people quickly find nearby pharmacies that have the medicine they need, especially when locating medicine is urgent.

Focus: Medicine availability and pharmacy discovery.

View GitHub Repository

3. eCommerce — Haroni Building

How I Built It

  1. Identify the needs of local vendors who want to list products online.
  2. Plan the product listing and customer browsing experience.
  3. Build the relevant pages and shopping workflow for the store.
  4. Test the main user flows and refine the store experience.

Technologies Used

  • Node.js and Express.js for the backend.
  • PostgreSQL, accessed with the pg package, for database storage.
  • bcrypt for password hashing and JSON Web Tokens (JWT) for authentication.
  • CORS and dotenv for backend configuration.

This project is an online store for local vendors in Wolaita Sodo, helping them list products and reach customers online.

Focus: E-commerce for local businesses.
